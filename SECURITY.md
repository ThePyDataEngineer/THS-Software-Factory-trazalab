# Política de Seguridad

## Versiones Soportadas

| Versión | Soportada |
|:---|:---:|
| main (desarrollo) | ✅ |
| Releases etiquetados | ✅ (hasta siguiente release) |

## Reporte de Vulnerabilidades

**No abra issues públicos** para vulnerabilidades.

Envíe reporte a: **security@thehumansoftware.com**

Incluya:
- Descripción del impacto y vector de ataque.
- Pasos de reproducción (mínimos).
- Versión/commit afectado.
- Mitigación conocida (si aplica).

## Divulgación Responsable

- Acuse de recibo: ≤ 48h.
- Evaluación inicial: ≤ 7 días.
- Parche y release: ≤ 30 días (crítico) / 90 días (moderado).
- Coordinación de divulgación pública tras parche disponible.

## Alcance

Cubre: `trazalab-core`, `trazalab-wasm`, `web/`, `fixtures/`, CI/CD.
No cubre: infraestructura GitHub, dependencias upstream (reportar a sus mantenedores).
