# G5–G6 · Extensión de superficie sin reescritura

G5: si se autoriza, evaluar Tauri conservando inicialmente la UI y el motor Wasm. Comparar web y desktop con mismo corpus. El adaptador nativo Rust sólo si se demuestra necesidad y paridad. Code-OSS/Theia se reabren únicamente si hay un requisito de workbench que Tauri/web no cubren. Verificar instalación Windows x64 en máquina limpia, política WebView2, arranque, guardado, actualización, rollback y desinstalación. Diferenciar instalar offline de operar offline. Usar permisos estrechos por ventana, no shell ni acceso a rutas arbitrarias. Probar denegación de API y recuperación de proyecto. Firma, publicación y actualizaciones reales quedan fuera del mandato inicial. Referencia: https://v2.tauri.app/distribute/windows-installer/ y https://v2.tauri.app/security/capabilities/.

G6: antes de ejecutar lenguajes adicionales, importar traza de un segundo productor sobre el mismo caso. Declarar equivalencia de resultado, de hitos o exacta; no exigir igualdad de instrucciones internas si se comparan hitos. Registrar productor, versión, variante y límites. Cada lenguaje tiene tres niveles distintos: importar, instrumentar, ejecutar; no anunciar soporte donde sólo hay un ejemplo. No ejecutar código de un proyecto importado. No backend, BD remota ni marketplace sin requisito y decisión separados.
